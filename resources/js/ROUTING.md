# Роутинг в приложении Explorer of the Universe

## Общая архитектура

Приложение использует гибридный подход для роутинга:
- **Серверный роутинг** через Laravel для API и основных страниц
- **Клиентский роутинг** через Inertia.js для навигации между страницами

## Серверные маршруты

### Веб-маршруты ([routes/web.php](file:///e:/work/the-explorer-of-the-universe/routes/web.php))
- `/` - главная страница (welcome)
- `/my` - личный кабинет пользователя (защищенный маршрут)

### API-маршруты ([routes/api.php](file:///e:/work/the-explorer-of-the-universe/routes/api.php))
- `/api/auth/*` - аутентификация (регистрация, вход, выход, обновление токена)
- `/api/satellite/*` - управление спутником
- `/api/systems/*` - информация о звездных системах
- `/api/discoveries/*` - открытия
- `/api/achievements/*` - достижения
- `/api/planets/*` - именование планет
- `/api/admin/*` - административные функции

## Клиентские маршруты

### Основные страницы
- `/` - компонент `welcome`
- `/my` - компонент `my`

### Управление навигацией

Для навигации между страницами используется утилита `navigate` из файла `routes.tsx`:

```typescript
import { navigate } from '@/routes';

// Переход на главную страницу
navigate('/');

// Переход в личный кабинет
navigate('/my');
```

### Защищенные маршруты

Для защиты маршрутов, требующих аутентификации, используется компонент `ProtectedRoute`:

```typescript
<ProtectedRoute>
    <MyPage />
</ProtectedRoute>
```

## Добавление новых страниц

1. Создайте новый компонент страницы в директории `resources/js/pages/`
2. Добавьте маршрут в файл `routes/web.php` на стороне Laravel
3. Если необходимо, добавьте маршрут в объект `routes` в файле `resources/js/routes.tsx`

## Обработка ошибок

Все ошибки навигации и роутинга обрабатываются через систему уведомлений, реализованную в `AlertStore`.
